## review-log.md 用途

记录做错、思路模糊、或者超过预期用时的题目，附日期。用于后续按专题做针对性复盘，不是把所有错题堆在一起从头到尾重做。

## 笔记字段说明

简单题：思路、代码、复杂度三项，不展开。

中等及困难题：题号与链接、标签、思路（含关键转折点的推导）、复杂度对比（暴力法与优化法）、代码、易错点、关联题目，全部字段都写。参见同目录下的示例笔记文件。
