# 003. 无重复字符的最长子串

**链接**：https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/?envType=study-plan-v2&envId=top-100-liked

**标签**：滑动窗口,哈希表, 数组　|　难度：中等

## 思路

维护一个[left, right]的窗口，其中left是这个无重复字符子串的起始位置，right是遍历到的字符位置。

遍历字符串通过移动右边界right实现

如果遍历到的当前字符在这个窗口中出现过，向右移动左边界到该字符上一次出现位置的下一个位置，使这个子串中无重复字符，更新当前位置。

每次移动right后，该长度就是right - left + 1, 通过max( , );比较选出最大值。

## 复杂度分析

时间复杂度：O(n)。我们只需要通过 right 指针遍历一次字符串，内部的操作都是 O(1) 的数组查找与赋值。

空间复杂度：O(1)。我们只开辟了一个大小为 128 的定长数组 last_pos，占用的内存是常数级别的。

## 代码

```CPP
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
    //使用一个数组记录每个字符上一次出现的位置，初始化为-1
    vector<int> last_pos(128, -1);
    
    int max_len = 0;    //记录最大长度
    int left = 0;       //窗口左边界

    //右窗口开始向后遍历
    for (int right = 0; right < s.length(); ++right) {
        char current_char = s[right];   //当前字符

        //如果当前字符在窗口中出现过
        if (left <= last_pos[current_char]) {
            //左边界要跳到该字符上一次出现位置的下一个位置
            left = last_pos[current_char] + 1;
        }
        //更新字符最新位置
        last_pos[current_char] = right;

        //计算并更新最大长度
        max_len = max(max_len, right - left + 1);

    }
    return max_len;
    }
};
```

## 易错点

优化的滑动窗口利用了数组/哈希表直接记录下标。当发现右边界字符 s[right] 重复时，左指针 left 根本不需要一步步挪，它可以通过查询记录，一瞬间“闪现（跳跃）”到上一次该字符出现位置的下一个跳板上
这把出窗操作的时间直接压缩到了 O(1)。

判断字符是否在窗口中出现过通过左边界和该字符上一次出现的位置所比较，如果出现的话左边界需要跳转到新的位置
